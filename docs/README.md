# Dokumentacja projektu

Ten katalog zawiera szybka mape kodu i opisy segmentow systemu.

## Jak czytac
- Zacznij od [Code Map](code-map.md).
- Sprawdz [Plan Summary](plan-summary.md), jesli potrzebujesz szybkiego statusu wykonania.
- Potem wejdz w segment, ktory Cie interesuje.
- Na koncu sprawdz [Onboarding](onboarding.md), jesli wracasz do projektu po przerwie.

## Zasada aktualizacji
Aktualizuj dokumentacje po kazdej zmianie, ktora:
- dodaje nowy modul,
- przenosi odpowiedzialnosc miedzy plikami,
- zmienia glowny flow (np. event -> consequence -> action).
